# Laboratorio REST API - Ejercicio 1

Listado de personajes de Rick & Morty usando la API REST pública (https://rickandmortyapi.com) con Axios.

- `/characters` → listado (primera página de la API, 20 personajes)
- `/characters/:id` → detalle del personaje (segunda llamada a la API)

He cambiado las escenas, rutas y pods de `hotel-collection` / `hotel` a `character-collection` / `character`.

## Cómo arrancarlo

```bash
npm install
npm start
```

Abrir http://localhost:8080
